# Working brand sheet

This is a design implementation sheet based on the repository's existing tokens and font setup. It is not a new official brand approval.

- Voice: direct, practical, confident, and human; explain the next step without hype.
- Display type: Anton for compact, high-impact transport/dispatch headings.
- Interface/body type: Archivo for readable UI and long-form copy; Inter remains available for supporting text.
- Data/support type: IBM Plex Mono for IDs, status labels, and operational metadata.
- Ink: warm charcoal near-black (`oklch(0.16 0.008 45)`).
- Paper: warm cream (`oklch(0.955 0.006 90)`).
- Signal: single rubric-red family using existing `--hazard` and `--hazard-deep` tokens.
- Signature element: dispatch-ledger details such as verified dates, route labels, and status chips, used sparingly to make offer facts scannable.

Pattern direction: type-led hero, structured offer comparison, three-step process, and FAQ accordion. The visual system should feel like a clear dispatch desk rather than a generic SaaS dashboard.
