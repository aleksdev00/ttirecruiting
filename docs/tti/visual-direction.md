# Visual direction decision

## Direction A: Dispatch ledger (selected)

Warm paper, charcoal blocks, a single red signal, Anton display headlines, and monospaced verification/status details. Offer cards read like clear dispatch records. Strengths: aligns with the existing repository tokens, makes facts scannable, and supports an admin shell without creating a second visual language.

## Direction B: Highway daylight

Bright white surfaces, navy text, blue/orange route accents, and photography-led cards. Strengths: familiar recruiting tone and broad accessibility. Weaknesses: conflicts with the current token system, risks a generic job-board feel, and introduces an unapproved palette/asset burden.

## Decision

Continue with Direction A. It is the smallest coherent change from the existing site, keeps the required driver facts prominent, and can scale from public pages to the private admin panel. The official logo/brand approval and authentic photography remain unresolved; no generated or stock image is treated as TTI proof.
